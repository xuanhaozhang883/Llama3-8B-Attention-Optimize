## 需要注意的失败项

1. **Icarus 14 的 N2 wrapper elaboration 失败，但 XSim 通过。** Icarus 报 enum 显式 cast 和 declaration-after-use 绑定错误；同一套源文件由 Vivado 2025.2 的 `xvlog + xelab + xsim` 成功编译、展开并仿真 PASS。因此这是工具兼容性问题，不能把 Icarus 失败当作 N2 wrapper 功能失败。
2. **历史 P6 checkpoint 对当前文本快照 fail-closed。** GitHub API 文本抓取会标准化换行，且 checkpoint 本身面向较早实现状态，因此不能用这个选择性文本快照做 byte-for-byte SHA-256 复验；完整错误已保存在 `p6_checkpoint_current_head.log`。
3. **当前 head 的本机 Vivado N2 real-IP synth 没有闭合。** 三次尝试都成功获得 `Synthesis/xczu15eg` 许可证，但 Vivado 子进程/主进程异常退出：两次发生在 FP32 IP synth，一次复用匹配 IP 后以 `0xC0000374` heap corruption 退出。日志没有给出 RTL 语法、DRC 或许可证失败，因此归类为本机 Vivado 进程环境失败，不能替代综合 PASS。
