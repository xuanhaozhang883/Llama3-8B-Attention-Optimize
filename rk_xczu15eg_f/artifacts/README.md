# Generated artifacts

This directory receives the generated:

```text
rk_xczu15eg_f_pl_selftest.bit
rk_xczu15eg_f_pl_selftest.ltx
```

Bitstreams and debug probe files are build products. Stable pairs should be
published through a GitHub Release or controlled artifact store with a
manifest that records the Git commit, Vivado version, exact part, PCB
revision, timing result, and hardware-validation status.

Always program the `.bit` and associate the `.ltx` generated by the same
build. A stale/mismatched `.ltx` can make VIO/ILA cores absent or incorrectly
mapped even though FPGA programming succeeds.

The `.bit` is about 28.7 MB, so do not add it to normal Git history without
an agreed Git LFS policy. The recommended handoff is a GitHub Release or
controlled artifact store containing both files plus `MANIFEST.md`.
